# Presentation pack

- **`PRESENTATION.md`** — основной длинный контент защиты (текст + таблицы + картинки). Источник истины для слайдов.
- **`figures/`** — сводные графики (кривые, zoo IoU, domain gap).
- Формальный близнец: [`docs/FINAL_CASE_REPORT.md`](../../docs/FINAL_CASE_REPORT.md).

PPTX: `scripts/build_pptx.py` собирает короткий черновик и **не** парсит `PRESENTATION.md`. Для сдачи опирайтесь на markdown.
